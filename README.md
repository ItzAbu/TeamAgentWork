# Progetto MVP

Benvenuto nel progetto MVP!

## Come avviare il sito

1. Assicurati di avere Node.js installato sul tuo computer.
2. Apri il terminale nella cartella `progetto`.
3. Installa le dipendenze (se presenti) o avvia direttamente il server di sviluppo locale aprendo il file `index.html` nel tuo browser preferito, oppure usando un server locale come `npx serve` o Live Server in VS Code.

### Esempio rapido con Python (se installato):
```bash
python3 -m http.server 8000
```
Poi apri il browser all'indirizzo `http://localhost:8000`.
